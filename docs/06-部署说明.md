# 校园二手交易平台 部署说明

## 1. 开发环境部署
参见 [`00-环境配置手册.md`](./00-环境配置手册.md)，从零搭建并启动前后端。

## 2. 生产部署

### 2.1 后端打包
```bash
cd backend
mvn clean package -DskipTests
# 产物：target/secondhand-1.0.0.jar
```

运行（通过环境变量注入敏感配置，不落盘）：
```bash
java -jar target/secondhand-1.0.0.jar \
  --spring.profiles.active=local \
  --spring.datasource.password=你的MySQL密码 \
  --DEEPSEEK_API_KEY=sk-你的Key
```
> 或继续用 `application-local.yml`（部署机上也建一份本地配置）。

### 2.2 前端打包
```bash
cd frontend
npm run build
# 产物：dist/
```

用 Nginx 托管 `dist/`，并把 `/api` 反代到后端：
```nginx
server {
    listen 80;
    root /var/www/secondhand/dist;
    index index.html;
    location / {
        try_files $uri $uri/ /index.html;   # SPA 路由回退
    }
    location /api/ {
        proxy_pass http://127.0.0.1:8081/;
    }
}
```

### 2.3 中间件
- Redis、RabbitMQ、MySQL 以系统服务方式常驻（Windows 服务 / systemd）。

## 3. 演示脚本（一键启动）

本地演示时按顺序执行：

```bash
# 1. 启动 Redis（Windows 解压目录）
tools/redis/redis-server.exe &

# 2. RabbitMQ（installer 已注册服务，或手动）
#    net start RabbitMQ

# 3. 后端
cd backend && mvn spring-boot:run -Dspring-boot.run.profiles=local

# 4. 前端（新终端）
cd frontend && npm run dev
```

浏览器打开 http://localhost:5173，用学号 `20210001` 登录演示。

## 4. 环境变量清单

| 变量 | 说明 | 默认 |
|---|---|---|
| `MYSQL_USER` | MySQL 用户名 | root |
| `MYSQL_PASSWORD` | MySQL 密码 | 需配置 |
| `DEEPSEEK_API_KEY` | DeepSeek Key | 需配置 |

> 后端 `application.yml` 已用 `${VAR:默认值}` 占位符，可用环境变量覆盖，避免把密钥写进配置文件。
