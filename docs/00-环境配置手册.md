# 环境配置手册（从零跑通 Demo）

> 本文档面向**团队其他成员 / 评审老师 / 任何一台干净电脑**，目标是照着操作，在 **30 分钟内**把「校园二手交易平台」完整跑起来（后端 + 前端 + 数据库 + 中间件 + AI）。

---

## 一、技术栈与版本要求

| 组件 | 版本要求 | 用途 | 默认端口 |
|---|---|---|---|
| JDK | **17** | 后端运行 | — |
| Maven | 3.8+ | 后端构建 | — |
| MySQL | 8.0 | 数据库 | 3306 |
| Redis | 5.0+（Windows 用 tporadowski 5.0.14） | 缓存/秒杀/Geo/BitMap/HLL | 6379 |
| RabbitMQ | 3.13（含 Erlang OTP 26） | 秒杀异步下单 | 5672 / 15672 |
| Node.js | 18+（建议 20+） | 前端构建 | — |
| npm | 随 Node | 前端依赖 | — |

> 说明：Redis 与 RabbitMQ 只在 Windows 下需要额外安装。macOS / Linux 可用 `brew` / `apt` 一行装好，其余步骤完全一致。

## 二、安装各组件

### 1. JDK 17
- 下载：Oracle JDK 17 或微软 OpenJDK 17（https://learn.microsoft.com/java/openjdk/download）
- 安装后验证：
```bash
java -version   # 应显示 17.x
```

### 2. Maven
- 下载二进制包：https://maven.apache.org/download.cgi
- 解压后把 `bin` 目录加入系统 `PATH`
- 验证：
```bash
mvn -v   # 应显示 Maven 3.8+
```

### 3. MySQL 8.0
- 下载安装：https://dev.mysql.com/downloads/installer/ （Windows）或 `brew install mysql` / `apt install mysql-server`
- **记住你设置的 root 密码**（后面配置要用）
- 验证：
```bash
mysql -u root -p
```

### 4. Redis（Windows 重点）
Windows 没有官方 Redis，推荐 **tporadowski/Redis for Windows**（解压即用，免安装）：
1. 下载 `Redis-x64-5.0.14.1.zip`（https://github.com/tporadowski/redis/releases）
2. 解压到项目 `tools/redis/` 目录（或任意目录）
3. 启动：
```bash
redis-server.exe
```
4. 验证：
```bash
redis-cli.exe ping   # 返回 PONG
```

> macOS/Linux：`brew install redis` 或 `apt install redis-server`，然后 `redis-server`。

### 5. RabbitMQ（Windows 重点）
RabbitMQ 依赖 Erlang：
1. 先装 **Erlang OTP 26.x**：https://www.erlang.org/downloads（或 RabbitMQ 官方给的 Erlang 版本）
2. 再装 **RabbitMQ 3.13.x**：https://www.rabbitmq.com/install-windows.html（installer 会自动注册 Windows 服务）
3. 启用管理界面（可选，用于可视化查看队列）：
```bash
rabbitmq-plugins enable rabbitmq_management
```
4. 验证：浏览器打开 http://localhost:15672 ，账号密码默认 `guest/guest`

> macOS/Linux：`brew install rabbitmq` 或 `apt install rabbitmq-server`。

### 6. Node.js
- 下载 LTS：https://nodejs.org/ （建议 20 LTS）
- 验证：
```bash
node -v   # 18+ 即可
npm -v
```

## 四、初始化数据库

```bash
# 在项目根目录执行（会创建库 + 表 + 测试数据）
mysql -u root -p < sql/init.sql
```

执行后验证：
```bash
mysql -u root -p -e "USE campus_secondhand; SHOW TABLES;"
```
应看到 `tb_user` / `tb_goods` / `tb_order` / `tb_follow` 四张表。

> ⚠️ 若中文乱码或插入报 `Incorrect string value`，改用：
> ```bash
> mysql --default-character-set=utf8mb4 -u root -p < sql/init.sql
> ```

## 五、配置后端密钥

后端敏感配置（MySQL 密码 + DeepSeek Key）**不提交到仓库**，需要每个成员自己建一份本地配置：

```bash
cd backend/src/main/resources
# 复制一份本地配置（已被 .gitignore 忽略）
cp application.yml application-local.yml
```

编辑 `application-local.yml`，填入你自己的值：

```yaml
spring:
  datasource:
    password: 你的MySQL密码

deepseek:
  api-key: sk-你的DeepSeekKey
```

> - **MySQL 密码**：就是你第 2 步装 MySQL 时设的那个。
> - **DeepSeek Key**：团队公用一个即可，从 https://platform.deepseek.com 申请；没有 key 时，AI 模块会自动降级返回"暂不可用"，不影响其他功能。

## 六、启动后端

```bash
cd backend
mvn spring-boot:run -Dspring-boot.run.profiles=local
```

看到下面这行即启动成功：

```
Started SecondhandApplication in X seconds
Tomcat started on port 8081
```

后端启动时依赖 **Redis（6379）和 RabbitMQ（5672）已启动**，请先确保它们开着。

## 八、验证 Demo 跑通（验收清单）

按下面顺序点一遍，全部通过即 demo 成功：

1. **登录**：学号填 `20210001`，点「发送验证码」→ 输入提示的验证码 → 登录成功。
2. **浏览商品**：首页能看到 4 条测试商品（高等数学教材 / iPad 2021 / 通勤自行车 / 机械键盘）。
3. **商品详情缓存**：点进任意商品，能看到详情；后端 Redis 里会出现 `cache:goods:{id}` 键。
4. **限时抢购**：进「限时抢购」页，点机械键盘「立即抢购」，提示成功；MySQL `tb_order` 里多一条订单，Redis `seckill:stock:4` 库存减 1。
5. **附近好物**：点「发布商品」发一个带经纬度的商品，再到「附近好物」页查询，能看到它按距离返回。
6. **每日签到**：进「每日签到」页点签到，连续天数 +1。
7. **AI 助手**：进「AI 助手」点「获取推荐」，返回带理由的推荐列表；选一个商品问"这个价格值吗"，返回议价建议。
8. **我的订单**：能看到刚才抢购/购买产生的订单，并能流转状态（已拍 → 面交中 → 已完成）。

## 九、常见问题（FAQ）

| 现象 | 原因 | 解决 |
|---|---|---|
| 后端启动报 `Access denied for user 'root'` | MySQL 密码不对 | 改 `application-local.yml` 的 `password` |
| 后端启动报 Redis 连接失败 | Redis 没启动 | 先启动 `redis-server.exe` |
| 后端启动报 RabbitMQ 连接失败 | RabbitMQ 没启动 | Windows 服务里启动 RabbitMQ，或 `rabbitmq-server` |
| 前端请求后端报跨域/网络错误 | 后端没启动或端口不对 | 确认后端 8081 已启动；前端 `api/request.js` 的 `baseURL` 是否 `http://localhost:8081` |
| 商品详情/发布接口 404 | 详情路径是 `/goods/detail/{id}` | 确认后端代码是最新版（详情路径已改为带 `/detail`） |
| 附近好物查不到 SQL 插入的测试商品 | 测试数据没走发布接口，无 GEO 索引 | 通过「发布商品」发一条带经纬度的即可搜到 |
| 抢购提示"该商品不支持抢购" | 商品 `is_hot` 不是 1 | 用 `is_hot=1` 的商品（如机械键盘） |
| AI 返回"暂不可用" | DeepSeek Key 无效或没配 | 检查 `application-local.yml` 的 `api-key`，或确认网络能访问 `api.deepseek.com` |
| 验证码提示里有中文乱码 | 终端编码 | 不影响功能，验证码数字正常即可 |
